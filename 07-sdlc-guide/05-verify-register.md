# [VERIFY] Register

A guide is stable only when open facts are tracked. This register consolidates the `[VERIFY]` items in the repository.

**Status key:** **Sourced** = found in SAP documentation or SAP publications on the date shown (still re-confirm for the client's edition and contract). **Partly** = some elements sourced, others open. **Open** = not found. "Sourced" does **not** mean contractually committed: SAP news articles are marketing statements. Evidence is in `_research/sap-specific-evidence.md` (section numbers cited) and `_research/forecasting-kg-mcp-evidence.md`. Last reviewed 2026-11-23.
